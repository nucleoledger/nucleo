# ADR-002-tiempo-declarado-vs-demostrable

**Estado:** aceptada · **Fecha:** 2026-08-31 · **Fuentes:** docs/CONCEPTO-v1.2-es.md §9

El timestamp local del bloque es tiempo declarado. El tiempo demostrable de una entrada es el mínimo de los timestamps de cosignatures de testigos (y tokens RFC 3161 si existen). El recibo muestra ambos con etiquetas separadas. Verificado: ninguna TSA ecuatoriana ofrece RFC 3161 abierto sin contrato; los testigos C2SP son la fuente primaria gratuita.
