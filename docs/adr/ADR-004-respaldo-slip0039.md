# ADR-004-respaldo-slip0039

**Estado:** aceptada · **Fecha:** 2026-08-31 · **Fuentes:** docs/CONCEPTO-v1.2-es.md §9

La KEK se respalda con SLIP-0039, umbral 2-de-3 por defecto (3-de-5 multi-socio), tarjetas impresas con UX guiada. Rotacion de identidad de firma: bloque especial firmado por la llave saliente. Llave perdida: nueva identidad anclada a testigos + acta de socios; la discontinuidad queda visible en la cadena.
